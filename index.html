Standard output

CTI V2 preset: 0.83-inch binding margin, 5.29-inch siddur width, 2.04-inch companion column, 0.28-inch outside margin, upper instruction area, separate corner block, and bottom status strip. All regions are invisible in the PDF.

These controls define a consistent maximum text block inside the protected siddur region. Source pages keep their original proportions.

The companion column is reserved for future reusable blocks. The siddur page is fitted only inside its protected region; this first version does not automatically extract the siddur region from a V2 page.

The new page number is fixed high in the upper outside corner (left on left-hand pages, right on right-hand pages); source artwork is scaled proportionally, never stretched.
