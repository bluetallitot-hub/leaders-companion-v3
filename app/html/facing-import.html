Leader's Companion V3

Facing Siddur page preparation

Inspect the original scan, draw separate crop rectangles, and fit the original printed text inside the approved V3 Siddur Text areas.

1. Upload source

For a single scanned spread, select the same source page for both outputs. For two separate scanned pages, choose each page independently. Assign English and Hebrew by selecting the correct regions; the tool does not guess language.

2. Select the printed regions

Drag inside a blue rectangle to move it; drag its lower-right handle to resize. You can also enter exact crop percentages. Exclude original page numbers and unnecessary white margins. The crop applies to the original PDF, not a screenshot.
