Leader's Companion V3

Import facing Siddur pages

Upload a PDF containing a two-page spread. Split the English and Hebrew sides, fit each scan inside the approved V3 Siddur Text box, and download a two-page PDF.

1. Source

A facing spread must contain both pages on one PDF page. No OCR or translation is performed: original scanned lettering is preserved.

2. Approved template

The tool loads docs/master-template/Leaders_Companion_V3_Master_Template_v1.3_Blank.pdf from this repository. If that file has not yet been uploaded, choose it manually.

3. Build and review

Files are processed locally in your browser. Inspect the split and fit before approving the result. Back to page preparation
